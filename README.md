An open-world crime game in a fictional tropical coastal city, built by an AI agent for make.fun's "Make GTA 6" bounty.

Raka, a former courier, returns to Arunika and gets pulled into the port smuggling network. Drive, steal, run, and read the tide: the **Tide Clock** opens boat channels at high tide and a mud shortcut at low tide that police cars cannot follow.

## Play

Serve `game/` locally and open it in a desktop browser:

```sh
node serve.ts
# open http://localhost:8080
```

Keyboard + mouse. WASD drive / walk, E enter & steal cars, Space brake, Shift drift, mouse to shoot, Q switch weapon, R reload, J mission, V radio, M map, P pause.

## Tech

- three.js (vendored under `game/vendor/`), plain static files, no network requests.
- All art, characters, places, and music are original, generated by code.
- `main.ts` (Node 22, standard library only) copies `game/` and `screenshots/` to `/output` and writes `dossier.json`.
